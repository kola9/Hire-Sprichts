Comment publier ?

  1. Sur GitHub, ouvre le dépôt des APK › Releases › Draft a new release.
  2. Crée un tag (ex. v1.2.0), glisse le fichier .apk, puis Publish release.
  3. Reviens ici : choisis l'APK dans la liste, vérifie le build, puis Publier.

Supprimer une version ici ne supprime pas le fichier sur GitHub.
